# LemLib Path Files

Use `path.jerryio.com` to create paths for this code.

- Select LemLib format.
- Save `.txt` files into `static/paths`.
- The robot starting pose in code must match the path start.
- Lookahead usually starts around 10 to 15 inches.
- Smaller lookahead follows tighter.
- Larger lookahead is faster but looser.
- Check the flag direction so the robot does not start at the end of the path.

The example files in this folder are not real routes. Replace them after the
robot pose, wheel size, and odometry directions are trusted.
